## Sobre mí / About me

**🇨🇱 Español:** Desarrollador desde Chile. Construyo **apps Android nativas** (Kotlin + Jetpack Compose), **sistemas web** con identidad propia (React 19 + Vite + Tailwind 4) y **software Windows con IA local** (en desarrollo).
